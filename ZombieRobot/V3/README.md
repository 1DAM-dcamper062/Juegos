# Zombie Robot Arena

## Cómo instalar y ejecutar el juego en Windows

### 1. Descarga el código del juego

Descarga el archivo:

```text
ZombieRobotArena.java
```

### 2. Descarga Java

Descarga e instala **Java JDK** en tu ordenador.

### 3. Ejecuta el juego desde CMD

Abre **CMD** dentro de la carpeta donde has descargado el código del juego.

Ejecuta los siguientes comandos:

#### 1. Compilar el juego

```text
javac ZombieRobotArena.java
```

#### 2. Ejecutar el juego

```text
java ZombieRobotArena
```

Después de ejecutar el segundo comando, se abrirá el juego.
